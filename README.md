# Barcode Profit Finder

iPhone Safariを最優先に設計した、店舗せどり向けの静的PWAです。バーコード、値札、販売済み価格から利益・ROI・回転率を計算し、「買い・要確認・見送り」を素早く表示します。

## 主な機能

- ZXingによる EAN-13 / EAN-8 / UPC-A / UPC-E / CODE-128 のリアルタイム読取
- 背面カメラ優先、3秒間の重複検出抑止、読取成功時の振動と視覚フィードバック
- 通常スキャンはライブ映像のフレーム解析のみで、写真撮影・シャッター音・音声取得なし
- 任意の値札OCR（Tesseract.js）。明示操作時の1フレームだけをブラウザ内で一時解析し、保存・送信なし
- Google、メルカリ、Yahoo!フリマ、Yahoo!オークション、駿河屋、Amazonの検索画面を開く
- 最大5件の販売済み価格から中央値・平均・最安・最高・件数を算出し、中央値を想定売価へ反映
- 販売手数料、手取り、利益、利益率、ROI、損益分岐売価、回転スコアの自動計算
- 変更可能な5段階の仕入判定と高利益時の振動
- localStorageへの保存、検索、編集、削除、再計算、CSV出力、JSONバックアップ・復元
- 初回チュートリアル、固定下部ナビ、ダークモード、PWA更新通知、オフライン用アプリシェル

## プライバシーと規約

通常のバーコード読取では静止画を生成しません。値札OCRの一時画像はCanvasメモリ上だけで処理し、端末やサーバーへ保存しません。各販売サイトは検索画面を開くだけで、自動ログイン・購入・出品・スクレイピングを行いません。

## ローカル起動

カメラAPIはHTTPSまたはlocalhostでのみ利用できます。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開きます。

## テスト

```sh
npm run check
```

## 第三者ライブラリ

- `@zxing/browser` 0.2.1 / `@zxing/library` 0.23.0
- `tesseract.js` 7.0.0

ライセンス文書は `vendor/` 内に同梱しています。OCRエンジン本体と言語データは初回OCR時にTesseract.jsの既定配信元から読み込まれるため、初回の値札読取には通信が必要です。

## iPhoneでカメラが始まらない場合

1. LINEやGoogleアプリ等の内蔵ブラウザではなく、Safari本体で公開URLを開きます。
2. Safariのアドレスバー左側メニューから「Webサイトの設定」→「カメラ」→「許可」にします。
3. ホーム画面版だけで失敗するときは、Safari本体から直接開きます。
4. ほかのカメラアプリを閉じ、SafariまたはiPhoneを再起動します。

アプリは背面カメラ指定に失敗すると自動的に単純なカメラ指定へフォールバックし、失敗時は画面上にエラー識別名を表示します。
「カメラ端末診断」では、写真を撮らずにカメラAPI・権限・映像再生のどこで失敗したかを端末内だけで確認できます。
